# Third-party components

## StonkFly

The MaleCNS importer, visual projection, spiking kernel, and neural dynamics are provided by [nftechie/stonkfly](https://github.com/nftechie/stonkfly), pinned as a git submodule at commit `78ef3e05ab0fa086032098558d893667068944a0`.

## MaleCNS v1.0

The connectome data is produced by the MaleCNS collaboration and upstream contributors and distributed separately under Creative Commons Attribution 4.0. The setup script downloads the release from the official Janelia/Google Storage URLs and verifies the checksums committed by StonkFly.

The dataset is not committed to this repository. Publications and public demonstrations must cite the MaleCNS dataset and associated paper.
